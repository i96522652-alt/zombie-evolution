ZOMBIE EVOLUTION — компактный мобильный интерфейс

Открой index.html в Spck Editor и запусти Preview.
Если у тебя уже есть старая версия, замени её index.html этим файлом.
Сохранение использует localStorage браузера; старый прогресс с тем же ключом zombieSave сохранится, если браузер и адрес запуска совпадают.
Это локальный прототип. Telegram-подключение будет отдельным этапом.
