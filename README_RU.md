# ZOMBIE EVOLUTION — Telegram Mini App

## Что внутри
- `index.html` — игра, адаптированная для запуска в Telegram Web App.
- `.nojekyll` — служебный файл для GitHub Pages.

## 1. Опубликовать игру на GitHub Pages
1. Создай новый публичный репозиторий на GitHub, например `zombie-evolution`.
2. Загрузи в корень репозитория `index.html` и `.nojekyll`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, нажми **Save**.
6. Дождись публикации. GitHub покажет HTTPS-адрес примерно такого вида:
   `https://ТВОЙ-ЛОГИН.github.io/zombie-evolution/`

## 2. Подключить ссылку к Telegram-боту
1. Открой в Telegram `@BotFather`.
2. Отправь `/mybots` и выбери своего бота.
3. Открой **Bot Settings → Configure Mini App** (если этот пункт доступен) и укажи HTTPS-ссылку GitHub Pages.
4. Если настраиваешь кнопку меню: **Bot Settings → Menu Button → Configure menu button**. Укажи текст, например `Играть`, и ту же HTTPS-ссылку.
5. Открой своего бота и нажми кнопку `Играть`.

Названия пунктов BotFather могут немного отличаться в зависимости от версии интерфейса. Для прямого запуска также можно настроить Main Mini App в BotFather.

## Важно
- Не вставляй токен бота в `index.html` или в публичный GitHub-репозиторий.
- Эта версия сохраняет прогресс через `localStorage` на устройстве/веб-просмотрщике пользователя. Между разными устройствами прогресс автоматически не синхронизируется.
- GitHub Pages размещает только игру. Для команд, базы данных, рейтингов и облачного сохранения понадобится отдельный сервер/бэкенд.
- Ссылка должна открываться по HTTPS.
