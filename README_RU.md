# ZOMBIE EVOLUTION — спрайты v3

## Что нового
- Более детальная базовая форма зомби: глаза, пасть, зубы, шрамы, рваная одежда и пиксельные блики.
- Усилены детали трёх эволюционных веток: огонь, яд и электричество.
- Для типов противников добавлены отдельные пиксельные силуэты и палитры.
- Для бронированных, ядовитых и боссовых врагов есть дополнительные визуальные детали.
- Спрайты встроены прямо в `index.html` как SVG с `crispEdges`: отдельные картинки и внешние библиотеки не нужны.
- Сохранён баланс противников из предыдущей версии.

## Обновление на GitHub Pages
1. Распакуй архив.
2. Замени `index.html` в корне своего GitHub-репозитория этим файлом.
3. Подожди, пока GitHub Pages обновит сайт.
4. Открой игру в Telegram. Если видишь старую версию, перезапусти Mini App или обнови страницу.

Прогресс игрока хранится в localStorage и не должен сбрасываться при замене HTML, если адрес сайта и хранилище Telegram WebView остаются теми же.

## Проверка
Основной JavaScript прошёл проверку синтаксиса `node --check`. Это не заменяет тестирование в Telegram на реальном телефоне.
